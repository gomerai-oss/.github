## GomerAI

We build tools for running AI coding agents under rules people set and can check afterwards.

**[Governance Control System](https://github.com/gomerai-oss/governance-control-system)**: a person approves a
plan, one agent builds it, a different agent reviews it, and only a passed review merges into `main`. Every step is
an auditable GitHub pull request. Apache 2.0.
